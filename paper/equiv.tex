\subsection{Exact values and approximations}\label{subsec:values}

Each type \(A\) comes equipped with a set \(\Eval{A}\) of \emph{exact values}
and a set \(\Approx{A}\) of \emph{approximation values}, as defined in
\cref{fig:exact-approx}. Approximation values \(\Approx{A}\) are similar to the
exact values, except some parts might be ``discarded''~(represented by
\(\sundefined\)).\ly{But what are exact values? Explain them as well.} They
represent ``smaller'' values where certain computations are unneeded; \ie~they
are approximations of the exact values.

    \Approx{\TList{A}} &= \set{\snil} \cup \setbuilder{\scons{v_1}{v_2}}{v_1 \in \Approx{A}, v_2 \in \Approx{\TThunk{(\TList{A})}}}

We extend \(\Eval{\cdot}\) and \(\Approx{\cdot}\) to typing contexts. If
\(\Gamma = x_1 : A_1, \ldots, x_n : A_n \) is a typing context, then
\(\Eval{\Gamma}\) is the set of environments of shape \(\Gamma\) that bind
variables to exact values:
\[
  \Eval{\Gamma} = \setbuilder{x_1 \mapsto e_1, \ldots, x_n \mapsto e_n}{e_1 \in \Eval{A_1}, \ldots, e_n \in \Eval{A_n}}.
\]
\(\Approx{\Gamma}\) is defined similarly.

Exact values and approximations are connected by the relation \(\approxofZ\)
(\cref{fig:approx}). Intuitively, \(\approxof{a}{e}\), pronounced ``\(a\)
approximates \(e\)'', if \(a\) has the same shape as \(e\), but with some parts
possibly replaced by \(\sundefined\). If \(e \in \Eval{A}\), we write
\(\Approx{A}_{\approxof{\relax}{e}}\) to denote the set of values in
\(\Approx{A}\) that approximate \(e\):
\[
  \Approx{A}_{\approxof{\relax}{e}} = \setbuilder{a \in \Approx{A}}{\approxof{a}{e}} .
\]
Similarly, if \(\gamma \in \Eval{\Gamma}\), we write
\(\Approx{\Gamma}_{\approxof{\relax}{\gamma}}\) to denote the set of
environments that elementwise approximate \(\gamma\).

\paragraph{The lattice of approximations.}
Approximations come with a \emph{definedness} relation (\cref{fig:definedness}).
It is conceptually similar to the approximation relation: \(a \le a'\),
pronounced ``\(a\) is less defined than \(a'\)'', if \(a\) has the same shape as
\(a'\) with some parts replaced by \(\sundefined\).

\(\le\) has the following properties.
\begin{itemize}
\item If \(\approxof{a}{e}\) and \(a' \le a\), then \(\approxof{a'}{e}\).
\item \(\le\) is a partial order.
\item Any two approximations \(a_1, a_2 \prec e\) have a least upper bound
  \(a_1 \sqcup a_2\).
\item For any exact value \(e \in \Eval{A}\), there a least element in
  \(\Approx{A}\) that approximates \(e\), denoted by \(\bot_e\), or just
  \(\bot\) when \(e\) is clear from context.
\end{itemize}
Thus, the set of approximations of any exact value forms a bounded
join-semilattice.

\(\le\) can be extended to environments. Given \(\gamma \in \Eval{\Gamma}\) and
\(\gamma^A_1, \gamma^A_2 \prec \gamma\), we say that
\(\gamma^A_1 \le \gamma^A_2\) if each value in \(\gamma^A_1\) is less defined
than the corresponding value in \(\gamma^A_2\). The definedness relation on
environments inherits all of the properties of \(\le\) on approximations; in
particular, it is a bounded join-semilattice.

\subsection{Clairvoyance Semantics}\label{subsec:clairvoyance}

Clairvoyance semantics on \(\LB\) is a big-step operational semantics with the
judgment schema \(\EC{\gamma}{t}{c}{v}\): intuitively, \(c\) is the number of
\(\ttickZ\)s encountered while evaluating \(t\) to \(v\). As with Hackett and
Hutton's original clairvoyance semantics, our definition is based on
\emph{improvement theory}~\cite{moran1999}. Unlike their semantics, which is
based on an untyped calculus with implicit laziness points and costs, ours is
based on a typed calculus with explicit \( \tlazyZ \) and \( \tforceZ \)
operators.\ly{When you say it's different, say what is the difference.}\nc{How's
  this?}

We give the main rules for clairvoyance semantics in
\cref{fig:clairvoyance-base}. The \rulename{C-Lazy-Result} and
\rulename{C-Lazy-Undefined} rules state that, to evaluate a \( \tlazyZ \) term,

``empty'' value \( \sundefined \)~(\rulename{C-Lazy-Undefined}). This is the
key to clairvoyance semantics. The \rulename{C-Force} rule states that we can
only evaluate a value of \( \TThunkZ \) type if it \emph{is} a \( \sthunkZ \)
(\eg~we cannot \( \tforceZ \) \( \sundefined \)).

Hutton~\cite{clairvoyant} is that \(\LB\) explicitly manages laziness with
\( \tlazyZ \) and \( \tforceZ \) operators, so we must introduce nondeterminism

Note that \( \tfoldrZ \) is evaluated by first evaluating its list argument to a
value \(v\), then iterating over \(v\) via the auxiliary relation
\( \ECF{\gamma}{x_1}{x_2}{t_1}{t_2}{v_2}{c_1}{v} \). Here, \( t_1 \) is a
``function'' (a term with free variables) that returns a \( \sthunkZ \) and
takes two arguments: an element of the list, and a \( \sthunkZ \)
obtained by iterating over the rest of the list (or \( \sundefined \) if the
rest of the list is itself \( \sundefined \)).

\subsection{Demand Semantics}\label{subsec:demand-semantics}

Demand semantics is a deterministic semantics that interprets a term \( t \)
as a function \( \EDU{t} \) which takes two arguments: an \emph{exact}
evaluation context \( \gamma \), and an approximation value that represents
the output demand on the result of \( \EE{t}{\gamma} \). It produces a list of
minimal demands on \( \gamma \) and a computation cost. In summary, demand
semantics has the ``type'':
\[
  \EDU{-} : (t : \Gamma \vdash A) \to (\gamma : \Eval{\Gamma}) \times \Approx{A}_{\approxof{\relax}{\EE{t}{\gamma}}} \to \Approx{\Gamma}_{\approxof{\relax}{\gamma}} \times \N .
\]
Intuitively, demand semantics computes ``how much'' of the input \( \gamma \) is
required to compute a desired ``amount'' of the output \( \EE{t}{\gamma} \). It
also computes how much it costs to perform the computation.

\subsection{Equivalence}\label{subsec:equiv}

\paragraph{The clairvoyance translation.}

\begin{theorem}\label{prop:equiv-clairvoyance}
  \( \EC{\gamma}{t}{c}{v} \) if and only if \( \EL{\gamma}{\floor{t}}{(v, c)} \).
\end{theorem}

\paragraph{The demand translation.}

The following two theorems demonstrate the equivalence of clairvoyance and
demand semantics. Let \( \Gamma \vdash t : A \), \( \gamma \in \Eval{\Gamma} \),
and \( \approxof{a^A}{\EE{t}{\gamma}} \); and define
\( (\gamma^A, c) = \ED{t}{\gamma}{a^A} \).

\begin{proposition}[Cost existence]\label{prop:cost-existence}
  Let \( \gamma^A \le {\gamma^A}' \prec \gamma \).  Then there exists some \( {a^A}' \ge a^A \) such that \( \EC{{\gamma^A}'}{t}{c}{{a^A}'} \).  In particular, \( \EC{\gamma^A}{t}{c}{a^A} \).
\end{proposition}

\begin{proposition}[Cost minimality]\label{prop:cost-minimality}
  Let \( \approxof{{\gamma^A}'}{\gamma}, {a^A}' \ge a^A, c' \in \N \) such that \( \EC{{\gamma^A}'}{t}{c'}{{a^A}'} \). Then \( ({\gamma^A}', c') \ge (\gamma^A, c) \).
\end{proposition}

\begin{lemma}
  Let \( \Gamma = x_1 : A_1, \ldots, x_n : A_n \).  If \( \TB{\Gamma}{t}{B} \)
  and \( \gamma \in \Eval{\Gamma} \), then
  \( \TL{\Gamma, y^A : B}{\transD{t}{\Gamma}}{\TM{(\texttt{\(A_1\)\ *\
        \(\cdots\) *\ \(A_n\)})}} \),
\end{lemma}

\begin{lemma}[Semantics of the demand translation]\label{prop:dem-trans-sem}
  \( \EL{\gamma, y^A \mapsto a^A}{\transD{t}{\Gamma}}{(\verts{\gamma^A}, c)} \)
  if and only if (1)~\( \gamma^A \le \gamma \), and (2)~\(  \EC{\gamma^A}{t}{c}{a^A} \).
\end{lemma}
\begin{proof}
  By construction, applying \cref{prop:equiv-clairvoyance}.
\end{proof}

\begin{theorem}[Adequacy of the demand translation]
  Define \( (\gamma^A, c) = \ED{t}{\gamma}{a^A} \) and let \( {\gamma^A}' \ge \gamma^A \).  Then there exists some \( {a^A}' \ge a^A \) such that \( \EL{\gamma, y^A \mapsto {a^A}'}{\transD{t}{\Gamma}}{({\gamma^A}', c)} \).  In particular, \( \EL{\gamma, y^A \mapsto a^A}{\transD{t}{\Gamma}}{(\gamma^A, c)} \).
\end{theorem}
\begin{proof}
  By \cref{prop:dem-trans-sem} and \cref{prop:cost-existence}.
\end{proof}
